Local AI setup
Install the standalone engine once, then download a model. Large downloads require network access and several GB of free space. Administrators install shared components; each workspace keeps its own profile, memory and trained versions. The managed service uses local port 11435.
A small model is a starting point; it may produce weaker documents than a cloud API. You can switch providers above at any time while retaining workspace memory. The service runs until the host computer stops it; its files are kept under the data folder’s runtime directory.
